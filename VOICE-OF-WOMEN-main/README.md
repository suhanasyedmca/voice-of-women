# 🌸 VOW — Voice of Women

**Empowering Every Girl. Protecting Every Voice.**

VOW is a full-stack digital platform focused on empowering the girl child through innovative solutions across 4 core pillars: **Safety, Education, Economic Development, and Healthcare**.

## Features

1. **Safety Hub (Module 1)**: Aadhaar-verified SOS Alert System, live proximity-matching for helpers, Trusted Contacts, and Anonymous Reporting.
2. **Education Hub (Module 2)**: E-learning courses, Career Mentorship matching, Scholarships, and Study Planner.
3. **Economy & Career (Module 3)**: Job Portal, Microfinance/MUDRA loan explorer, Budget Planner, and Resume Builder.
4. **Healthcare Center (Module 4)**: Telemedicine portal, Daily wellness trackers (Water, Steps, Mood, Menstrual), and Maternal Care guides.
5. **VOW AI Chatbot**: Context-aware AI assistant with crisis keyword detection.
6. **Community Forum**: Safe space for sharing stories, asking questions, and networking.
7. **Admin Control Room**: Real-time SOS dashboard and platform analytics.

## Tech Stack

- **Frontend:** React (Vite), TypeScript, Tailwind CSS, Framer Motion, React Router, Zustand, React Hot Toast, Lucide React.
- **Backend:** Node.js, Express, MongoDB (Mongoose), Socket.io, JWT, Bcrypt.

## Setup & Installation

### Prerequisites
- Node.js (v18+)
- MongoDB (Local or Atlas)

### Backend Setup
1. `cd VOICE-OF-WOMEN-main/server`
2. `npm install`
3. Configure `.env` (MONGO_URI, JWT_SECRET, PORT=5000)
4. `npm run dev`

### Frontend Setup
1. `cd VOICE-OF-WOMEN-main/client`
2. `npm install`
3. `npm run dev`

The platform will be available at `http://localhost:5173`.
